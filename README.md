# ALEPH A-Class 웹서비스 보안 분석 및 보완

PHP 게시판의 취약점을 재현하고 코드를 수정한 뒤, GNS3에서 Web·DB·Mail 서버 사이의 접근 제어와 전송 암호화를 구성했습니다. 공격이 차단됐는지 확인하는 시험과 로그인·파일 업로드·메일 발송이 계속 동작하는지 확인하는 시험을 함께 수행했습니다.

## 담당 범위

초기 학습용 웹사이트는 팀원들과 제작했습니다. 이후 취약점 재현, 코드 수정, GNS3 토폴로지 구축, 보안 설정과 검증은 개인으로 수행했습니다.

## 주요 작업과 검증 결과

| 영역 | 적용한 조치와 확인한 결과 |
|---|---|
| 애플리케이션 | SQL Injection, 저장형 XSS, IDOR 등 10개 취약점을 분석했습니다. 검색 파라미터에 Prepared Statement를 적용한 뒤 같은 sqlmap 시험을 반복했고, 과제게시판에서 PHP 웹쉘은 차단되면서 정상 PDF는 업로드되는 것을 확인했습니다. |
| 네트워크 | Cisco ASAv로 Outside·DMZ·Inside를 분리했습니다. Web에서 DB 3306과 Mail 25로 연결되는 경로를 유지하고, 외부 호스트의 DB·Mail 접근과 같은 Inside 대역의 Mail↔DB 업무 포트 접근을 각각 시험했습니다. |
| 웹 요청과 전송 | ModSecurity와 OWASP CRS가 지정한 SQL Injection·XSS 요청을 HTTP 403으로 차단했습니다. 브라우저와 Web 사이에 HTTPS를 적용했고, Web에서 Mail로 보낸 재설정 메일이 STARTTLS를 사용해 배달된 것을 Postfix 로그에서 확인했습니다. |
